# Visual Language

> The Pernambuco Digital Standard establishes a shared visual language, not a single visual style.

## Purpose

The Visual Language provides guidance for composing digital interfaces using the Pernambuco Digital Standard.

It defines how foundations, components, and patterns should be expressed together to create clear, coherent, and context-appropriate experiences.

It helps AI agents make visual and compositional decisions that are not defined by individual components or design tokens alone.

## Scope

The Visual Language provides guidance for:

- Visual hierarchy
- Use of color
- Typography in composition
- Spacing and visual rhythm
- Surfaces and visual grouping
- Content density
- Visual emphasis
- Visual expression across different contexts

## Principles

### Consistent, Not Identical

Interfaces should be visually recognizable as part of the Pernambuco Digital ecosystem without being forced to look identical.

Use the Design System foundations as the common visual base, while allowing the composition and visual expression to adapt to the context of each experience.

### Context Drives Expression

Visual decisions should reflect the purpose, content, and primary task of the experience.

A transactional service, an institutional page, a documentation page, and a campaign experience may require different levels of visual expression while remaining consistent with the same Design System.

### Hierarchy Before Decoration

Visual emphasis should help users understand what is important, what they can do, and how information is organized.

Do not add visual elements only to make an interface more visually interesting. Use size, typography, color, spacing, and composition to establish meaningful hierarchy.

## Visual Hierarchy

Visual hierarchy establishes the relative importance of information and actions within an interface.

Use hierarchy to help users quickly understand:

- Where they are
- What the page is about
- What information is most important
- What action they should take
- What information is secondary

Hierarchy can be created through:

- Typography
- Size
- Weight
- Color
- Spacing
- Position
- Surface and contrast

Use these properties together rather than relying on a single visual treatment.

Avoid giving the same level of visual emphasis to multiple elements when they have different levels of importance.

## Color

Color should support hierarchy, identity, communication, and interaction.

Use the Design System color tokens as the foundation for all color decisions.

The primary color can be used not only for interactive elements, but also to create visual hierarchy, structure sections, reinforce identity, and emphasize relevant content.

Use color according to its role and context rather than applying the same color treatment uniformly across the interface.

Project-specific visual identities may introduce additional colors when appropriate, provided that they remain accessible and do not conflict with the semantic meaning of existing Design System colors.

Avoid using color only for decoration or applying strong colors to multiple elements without a clear visual purpose.

## Spacing and Visual Rhythm

Spacing should create structure, hierarchy, and rhythm within the interface.

Use spacing to:

- Group related information
- Separate unrelated content
- Establish hierarchy between sections
- Create visual pauses between major content blocks
- Support readability and scanning

Use larger spacing between distinct sections and smaller spacing between elements that belong to the same group.

Spacing should be consistent with the Design System spacing tokens while adapting to the hierarchy and structure of the content.

Avoid using the same spacing value between all elements or adding large gaps without a clear structural purpose.

## Surfaces and Visual Grouping

Use surfaces to establish relationships between content and create clear visual groupings.

Surfaces can be used to:

- Group related information
- Separate distinct sections
- Establish visual hierarchy
- Highlight important content
- Create contrast between content areas

Use the appropriate surface, border, elevation, or background treatment according to the importance and relationship of the content.

Not every content group needs to be contained within a card or bordered surface.

Prefer simpler groupings when spacing, typography, or alignment are sufficient to establish the relationship between elements.

Use stronger surface treatments when they provide a clear structural or communicative purpose.

## Content Density

Content density should reflect the purpose and complexity of the experience.

Use lower density when the experience requires reading, orientation, discovery, or strong visual emphasis.

Higher density may be appropriate when users need to compare, review, manage, or process larger amounts of information efficiently.

Adjust density through:

- Amount of information presented at once
- Spacing between content groups
- Number of elements visible within a section
- Content width
- Grouping and prioritization

Prioritize the information required for the user's primary task.

Avoid increasing density simply to fit more content on the screen or reducing density when it makes the experience unnecessarily long or inefficient.

## Visual Emphasis

Visual emphasis should be used intentionally to draw attention to information or actions that are important in the context of the experience.

Use visual emphasis through combinations of:

- Typography
- Color
- Size
- Spacing
- Contrast
- Position
- Imagery

Reserve stronger visual treatments for primary content, actions, or moments that require the user's attention.

Use visual emphasis to create clear focal points within the page.

Avoid applying strong visual emphasis to multiple elements with different levels of importance.

Avoid decorative emphasis that does not contribute to understanding, navigation, or the purpose of the experience.

## Typography in Composition

Typography should establish hierarchy, support readability, and contribute to the visual identity of the experience.

Use the Design System typography styles as the foundation for typographic decisions.

Use differences in size, weight, spacing, and color to distinguish:

- Page titles
- Section headings
- Supporting information
- Body content
- Labels and metadata
- Actions

The strongest typographic emphasis should generally be reserved for the purpose and primary content of the page.

Supporting text should remain visually subordinate to the content it explains.

Use shorter and more focused headings when the interface requires quick scanning.

Avoid using large or highly emphasized typography for multiple elements with the same level of importance.

## Visual Expression

The level of visual expression should reflect the context and purpose of the experience.

Use a more restrained visual expression when the primary goal is completing a task, processing information, or interacting with a service.

A more expressive visual treatment may be appropriate for institutional pages, platforms, campaigns, launches, or experiences focused on exploration and engagement.

Visual expression can be increased through:

- Stronger use of color
- Larger visual elements
- Imagery and illustration
- Distinctive section compositions
- Greater contrast between content areas
- More expressive typography

Expressive elements should support the purpose and identity of the experience rather than compete with its content or functionality.

Regardless of the level of expression, maintain consistency with the Design System foundations, accessibility requirements, and the overall Pernambuco Digital ecosystem.

## Imagery and Graphic Elements

Imagery and graphic elements can strengthen the identity, context, and visual expression of an experience.

Use imagery when it contributes to:

- Communicating the context or purpose of the experience
- Supporting understanding of the content
- Establishing a product or project identity
- Creating visual interest in experiences focused on discovery or engagement
- Supporting narrative or institutional communication

Use imagery and graphic elements according to the context of the experience.

Task-oriented interfaces should prioritize clarity and functionality over decorative imagery.

More expressive experiences may use photography, illustration, graphic compositions, or other visual elements to strengthen their identity.

Visual elements should remain consistent with the content, accessible, and subordinate to the user's primary task when functionality is the main goal.

Avoid adding imagery or decorative elements only to fill empty space or make an interface appear more visually complex.

## Adaptation to Context

Visual decisions should adapt to the context of the experience while preserving the foundations of the Pernambuco Digital Standard.

Consider the following factors:

- Purpose of the experience
- Primary user task
- Type of content
- Interaction complexity
- Information density
- Need for visual exploration
- Product or project identity

A service focused on completing a task should prioritize clarity, orientation, and efficiency.

A content-oriented experience may use more space, stronger editorial hierarchy, and more visual variation.

An institutional, exploratory, or campaign-oriented experience may use a higher level of visual expression when it supports its purpose.

Context should influence the composition and level of expression, but should not override Design System foundations, accessibility, or established interaction patterns.

## Expression by Context

The visual expression of an interface should adapt to the purpose and context of the experience.

The same Design System foundations can be composed with different levels of visual emphasis, density, color, imagery, and structure.

### Transactional Services

Services focused on completing a task should prioritize clarity, orientation, and efficiency.

Use:

- Clear page and section hierarchy
- Focused content areas
- Controlled visual density
- Clear primary and secondary actions
- Strong feedback and status communication
- Limited decorative elements

Avoid unnecessary visual complexity that could distract from the task.

### Content and Documentation

Experiences focused on reading, learning, or documentation can use a more editorial composition.

Use:

- Strong typographic hierarchy
- Generous spacing
- Clear content sections
- Visual examples when they support understanding
- Strong separation between major topics

Prioritize readability and content structure over interaction density.

### Institutional Experiences

Institutional pages should communicate identity, purpose, and credibility.

Use:

- Strong institutional identity
- Clear introductory hierarchy
- Structured content sections
- Appropriate use of imagery or graphic elements
- Visual emphasis for key messages and calls to action

The composition may be more expressive than a transactional service while maintaining the visual foundations of the Design System.

### Exploratory Experiences

Experiences focused on discovery, exploration, or interaction with large amounts of content may use a more expressive and flexible composition.

Use:

- Clear navigation and information hierarchy
- Visual grouping that supports exploration
- Appropriate use of imagery, illustration, or graphic elements
- Strong visual cues to guide discovery
- Product or project-specific identity when appropriate

Visual expression should support exploration without compromising clarity or accessibility.

### Campaigns and Experiences

Campaign, launch, and event-oriented experiences may use a higher level of visual expression.

Use:

- Stronger visual compositions
- More expressive color combinations
- Larger imagery or illustrations
- Distinctive section compositions
- More prominent visual storytelling

Expressive treatments should still support the purpose of the experience and maintain accessibility and consistency with the Design System foundations.

## Composition Guidance

Interfaces should be composed as a hierarchy of meaningful content and interaction areas, rather than as a collection of isolated components.

Each page should establish:

- A clear purpose
- A clear visual starting point
- A logical content hierarchy
- Distinct relationships between sections
- A clear primary action when applicable

Components should be selected and combined according to the content, task, and context of the experience.

The composition should create a coherent visual flow from the beginning of the page to the end.

Avoid assembling pages by placing components independently without considering their relationship, hierarchy, spacing, and visual emphasis.
